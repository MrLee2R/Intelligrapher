# 审美库索引

## 格式规范
每个审美文件必须包含：
1. `## 目标期刊列表`
2. `## 主色板（Primary）`：JSON 代码块，键 `primary`
3. `## 辅助色板（Secondary）`：JSON 代码块，键 `secondary`
4. `## 背景与网格建议`
5. `## 字体与字号`
6. `## 线型与标记规范`

## 已支持风格
- `civil-engineering.md`：Engineering Structures, Geotechnique 等
- `medicine.md`：The Lancet, NEJM, Nature Medicine 等
