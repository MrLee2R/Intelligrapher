# 医学科研绘图知识库

## 常用图表类型
1. **Kaplan-Meier 生存曲线**：标注删失数据、置信区间、Log-rank p 值。
2. **ROC 曲线**：标注 AUC、95% CI、最佳截断点。
3. **森林图（Forest Plot）**：Meta 分析用，标注权重、I²。
4. **热图（Heatmap）**：基因表达或相关性，标注聚类树、颜色标尺。
5. **瀑布图（Waterfall Plot）**：肿瘤疗效，标注缓解线（-30%）和进展线（+20%）。
6. **列线图（Nomogram）**：预测模型，标注总分计算线。

## 坐标轴规范
- 生存曲线：横轴随访时间（月），纵轴生存率（0-1），截断在 0 和 1。
- ROC 曲线：横轴 1-特异性（0-1），纵轴敏感性（0-1），对角线参考线必须显示。
- 森林图：横轴效应量（HR/OR/RR），纵轴研究名称，参考线（效应量=1）。

## 标注符号表
- HR：风险比；OR：比值比；RR：相对危险度；CI：置信区间。
- *p*：p 值；ns：不显著；****：p < 0.0001。
- CR/PR/SD/PD：疗效分级。

## 领域特殊要求
1. 涉及患者数据需在图注标注伦理批号。
2. 生存曲线必须在图例标注每组样本量（n=...）。
3. 组间比较必须标注检验方法和精确 p 值。
4. 临床效应量必须附带 95% CI。
5. 避免仅依赖颜色区分组别（需叠加线型或标记）。
