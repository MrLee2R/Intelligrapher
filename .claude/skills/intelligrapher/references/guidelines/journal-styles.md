# 顶刊通用排版速查

## Elsevier
- 单栏图宽：8.5 cm（~3.35 inch）
- 双栏图宽：17.4 cm（~6.85 inch）
- 分辨率：≥ 300 DPI（线图），≥ 600 DPI（照片）
- 格式偏好：TIFF, EPS, PDF
- 字体嵌入：必须嵌入，Arial / Times New Roman

## Springer
- 图宽：8.4 cm（单栏）或 17.4 cm（双栏）
- 必须提供矢量图（EPS/PDF），位图仅接受 TIFF
- 坐标轴标签使用 Arial 或 Helvetica
- 图注（caption）另附，不嵌入图中

## Nature 系列
- 单列图宽：8.9 cm（3.5 inch）
- 双列图宽：18.3 cm（7.2 inch）
- 字体限制：Arial, Helvetica, Times, Symbol 或其组合
- 线图分辨率 ≥ 1200 DPI，照片 ≥ 300 DPI
- 颜色模式：RGB（屏幕）或 CMYK（印刷），需注明

## IEEE
- 单栏图宽：8.89 cm（3.5 inch）
- 双栏图宽：17.78 cm（7.0 inch）
- 字体：Times New Roman 或 Computer Modern
- 图内文字 ≥ 8 pt
- 黑白印刷偏好，彩色需确认费用

## Science
- 图宽：≤ 13.3 cm（单栏）或 ≤ 17.8 cm（双栏）
- 格式：TIFF, EPS, PDF
- 所有文字可编辑，禁止栅格化文字

## 通用建议
- 图表尺寸按目标期刊的栏宽设置 `figsize`。
- DPI 统一设置为 300，出版前可按需提高。
- 保存格式优先 SVG → PDF → PNG（300 DPI）。
