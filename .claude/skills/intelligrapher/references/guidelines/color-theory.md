# 科研配色理论指南

## 色盲友好原则
- 避免仅依赖红-绿对比（红绿色盲占男性人口约 8%）。
- 推荐组合：蓝-橙、蓝-棕、紫-黄。
- 使用不同线型（实线/虚线）或标记形状作为颜色之外的区分维度。

## WCAG 2.1 对比度
- 正文文字与背景对比度 ≥ 4.5:1。
- 大号文字（≥ 18pt 或 14pt 加粗）与背景对比度 ≥ 3:1。
- 图表中的线条和标记至少满足 3:1。

## 连续色板（Sequential）
- 适用于有序数据（温度、浓度、高度等）。
- 推荐单色调变：从浅色到深色，如 `Blues`, `Oranges`, `viridis`。
- 避免使用彩虹色图（rainbow colormap），因为颜色亮度不均匀会误导感知。

## 离散色板（Diverging）
- 适用于以某个中心值为分界的数据（偏差、差异等）。
- 推荐：`RdBu_r`, `BrBG`, `PuOr`，中心点为中性色（白或灰）。

## 分类色板（Qualitative）
- 适用于无序类别数据。
- 色板颜色数 ≤ 8，超过时需使用线型/标记辅助区分。
- 推荐：`tab10`, `Set2`, `Paired`（matplotlib 内置）。

## 印刷注意事项
- 黑白打印时，颜色需转换为灰度可区分。
- 线条粗细差异 ≥ 0.5 pt 才能在灰度下区分。
- 避免使用纯黄（#ffff00）在白色背景上打印。
