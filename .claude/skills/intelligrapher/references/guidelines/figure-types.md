# 图表类型决策指南

## 决策树

```
数据类型？
├── 单变量分布 → 直方图 / 核密度图 / 箱线图
│   ├── 需看异常值 → 箱线图（box-plot）
│   └── 需看分布形态 → 直方图 + KDE
│
├── 两组对比 → 柱状图 / 箱线图 / 小提琴图
│   ├── 样本量小（n < 30）→ 柱状图 + 误差棒
│   └── 样本量大 → 箱线图 或 小提琴图
│
├── 多组对比 → 分组柱状图 / 箱线图矩阵
│
├── 两个连续变量 → 散点图
│   ├── 有重复点重叠 → 加抖动（jitter）或 半透明（alpha < 1）
│   ├── 需显示趋势 → 叠加回归线
│   └── 数据量大 → 2D 直方图 / Hexbin
│
├── 时间序列 → 折线图（line-plot）
│   ├── 数据点多 → 取消标记，仅保留线条
│   └── 多序列对比 → 用不同线型 + 颜色
│
├── 相关性矩阵 → 热图（heatmap）
│   ├── 需聚类 → 用 seaborn.clustermap
│   └── 仅需展示数值 → 热图 + 数值标注（annot=True）
│
├── 三部分占比 → 饼图（谨慎使用）/ 堆叠柱状图
│   └── 超过 5 个类别 → 改用 柱状图 或 树图
│
├── 地理空间 → 等值线图 / Choropleth / 散点地图
│
└── 分层/层级 → 树图 / 旭日图 / 桑基图
```

## 图表选择速查表

| 场景 | 推荐图表 | 不推荐 |
|------|----------|--------|
| 展示趋势 | 折线图 | 柱状图 |
| 展示分布 | 箱线图 / 小提琴图 | 柱状图（掩盖分布） |
| 展示占比 | 堆叠柱状图 | 饼图（人眼不擅长比较角度） |
| 展示关系 | 散点图 + 回归线 | 柱状图（丢失连续性信息） |
| 展示层次 | 树图 / 旭日图 | 嵌套饼图 |
| 展示流程 | 桑基图 / 流程图 | 复杂箭头图 |
| 生存分析 | Kaplan-Meier 曲线 | 柱状图 |
| 效果量汇总 | 森林图 | 表格 |

## 常见错误
1. **截断 y 轴**：从非零开始会夸大差异。
2. **双 y 轴**：读者难以同时比较两组不同量纲的数据。
3. **3D 效果**：引入透视畸变，扭曲数据比例。
4. **过度使用颜色**：同一图表中颜色 > 8 种会导致认知负荷过高。
5. **图内文字过小**：确保印刷后所有文字 ≥ 6 pt。
